# python-gaming-app

Standalone Python-only repository extracted from `algorithms` so you can run only Python code.

## Run

From this folder:

```bash
python containsduplicates.py
python containerwithmostwater.py
python groupanagram.py
python reverse_words.py
python validanagram.py
```

## Initialize as its own git repository

```bash
cd python-gaming-app
git init
git add .
git commit -m "Initial Python gaming app import"
```
